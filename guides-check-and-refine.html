Check the result and write a useful follow-up

Review facts, identify the gap and ask for a specific revision.

A polished answer can still miss the brief. Review it against your original requirements before copying it into client work or publishing it.

Check facts first

Compare names, numbers, features and dates with the material you supplied. Identify claims that need verification. The prompt builder cannot verify the response produced by another tool.

Describe the gap

“Try again” gives little direction. Say whether the answer is too long, aimed at the wrong audience, missing a required section or using an unsupported assumption.

Keep the five agreed pages and the WhatsApp enquiry route. Remove the payment integration because it was not requested. Return a shorter brief with three sections: Pages, Content needed and Open questions. Do not add a budget or delivery date.

Preserve what works

Name the parts you want to keep. This avoids unnecessarily replacing a useful structure while correcting one problem.

Use a follow-up in the same conversation

After receiving an answer from your AI tool, open “Improve response” in Prompt Ustad, describe the required changes and copy the generated follow-up into that same conversation. The builder does not read the other tool’s answer automatically.

Know when to stop

Check the result against the deliverable and your factual boundaries. For code, run relevant checks; for a website enquiry, verify actual delivery; for public claims, inspect the evidence. A convincing explanation is not a substitute for a working result.
